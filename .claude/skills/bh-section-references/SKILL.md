# Section references

Use `docs/design-system/section-references.md`. For the section you are redesigning, open two or
three examples from its free gallery with WebFetch, write down what makes the best ones work, then
design our own version within `docs/brand.md`. Never copy code, text or images. Then run
`bh-design-loop` for the critic pass and `bh-design-check` before committing.
