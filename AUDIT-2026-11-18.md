# Blue Hammer Remodeling — Site Audit (2026-11-18)

Scope: everything in `blue_hammer_remodeling_site/` as deployed from `main` (commit `c2bc549`) to
**https://bluehammermd.com** (Netlify project `bluehummer`, custom domain verified via Netlify API,
HTTPS + HSTS on, `www` and `http` 301 to the apex). 18 public HTML pages + `__forms.html`,
13 raster assets, `main.css` (23 KB), `main.js` (6 KB), `site-config.js`.

Method: manual pass with grep/node extraction over every page (titles, metas, canonicals, OG,
headings, JSON-LD parse, images/alt/lazy, internal links/assets), live HTTP probes of the production
host, Netlify API (site settings, forms, submissions), and content read-through of all pages.

Severity key: **critical** = loses leads or actively harms trust/indexing now · **high** = clear
ranking/UX/trust cost · **medium** = worthwhile, not urgent · **low** = polish.

Status key (added in the 2026-11-18 afternoon revision): **OPEN** = still live as of commit `c2bc549` ·
**WT** = already fixed in the uncommitted working tree before this revision · **FIXED** = fixed and
pushed by the agent in this run (see `AGENT-LOG.md` for commit hashes).
